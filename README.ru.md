# BackUpClaude

[English version](README.md)

> **Проект неофициальный.** Он не связан с Anthropic, компания его не поддерживает и не одобряла.

BackUpClaude бережёт ваши данные Claude и проекты: сессии, память и настройки Claude раз в час, папки проектов раз в сутки, в зашифрованных копиях. Это один файл, ставить ничего больше не надо. Бэкап делают [restic](https://github.com/restic/restic) и [rclone](https://github.com/rclone/rclone): мастер настройки устанавливает их сам, закреплённых версий и со сверкой хэшей. Ни сервера, ни аккаунта: у каждого человека свой пароль и свои копии.

**Статус: готовится версия 0.1.0.** Работает на Windows 10 и 11; macOS и Linux появятся позже. Репозиторий пока приватный, поэтому команда установки в одну строку ниже заработает только после его открытия, а до тех пор ставьте вручную. Копирование во внешнее хранилище **ещё не сделано**: мастер может запомнить адрес, но в этой версии туда ничего не копируется (см. [Ограничения](#ограничения)). Прочтите этот раздел, прежде чем на неё полагаться.

## Быстрый старт

Нужна Windows 10 или 11. Права администратора не требуются.

**Одна команда** в PowerShell:

```powershell
irm https://github.com/peregoood-ru/BackUpClaude/releases/latest/download/install.ps1 | iex
```

Она скачивает выпуск, сверяет SHA-256 с опубликованным `checksums.txt`, кладёт программу в `%USERPROFILE%\.backupclaude\bin`, добавляет эту папку в ваш PATH и запускает мастер.

**Вручную:** скачайте со страницы выпусков `backupclaude_<версия>_windows_amd64.zip` и `checksums.txt`, сверьте хэш (`Get-FileHash file.zip`), распакуйте и запустите:

```
backupclaude.exe setup
```

Мастер задаёт несколько вопросов, у каждого есть ответ по умолчанию, его принимает Enter:

1. **Где хранить локальную копию.** Любая папка вне Яндекс Диска, OneDrive, Google Drive и Dropbox: сервис синхронизации отправит в облако и удалённый, и испорченный файл. Мастер такие папки не принимает и предлагает другой диск.
2. **Внешняя копия.** `rclone:remote:папка`, `sftp:user@host:/path` или папка, либо пропустить. Пропустить можно, мастер прямо скажет, что это значит.
3. **Куда присылать сообщения о сбоях.** Никуда, в бота Telegram или на webhook.
4. **Навык `/backup` для Claude Code**, чтобы можно было попросить Claude проверить копии или вернуть сессию.

Потом он создаёт пароль, хранилище и расписание, делает первый снимок и показывает, как записать пароль на бумагу. **Сделайте это.** Без пароля копии не открыть, и восстановить его никто не сможет.

`backupclaude setup` можно запускать снова в любой момент: он меняет только то, что вы ответили, остальное не трогает. `backupclaude setup --yes` ничего не спрашивает и берёт ответы по умолчанию, а у каждого ответа есть флаг для скриптов (`backupclaude setup --help`).

### SmartScreen

Программа пока не подписана сертификатом разработчика. Если скачать файл браузером, Windows может написать *«Windows защитила ваш компьютер»*. Сначала сверьте SHA-256 файла с `checksums.txt` выпуска, потом нажмите **Подробнее**, **Всё равно запустить**. Команда установки выше скачивает файл сама, проверяет хэш и это предупреждение не вызывает.

## Команды

| Команда | Что делает |
| --- | --- |
| `backupclaude setup` | Мастер: проверяет компьютер, ставит restic и rclone, задаёт вопросы, создаёт пароль, хранилище, расписание и первый снимок. Безопасно запускать повторно |
| `backupclaude status` | В безопасности ли данные, простыми словами: возраст последнего снимка, размер, свободное место, последняя проверка, сбои |
| `backupclaude backup` | Снимок прямо сейчас всех включённых профилей (раздел «Что сохранять» в [docs/install.ru.md](docs/install.ru.md)), `--profile claude` или `projects` для одного из них, `--dry-run` ничего не сохраняет |
| `backupclaude list` | Снимки, сессии и проекты |
| `backupclaude restore` | Вернуть сессию (`--session`), проект (`--project`) или всё (`--all`) в новую папку; `--apply` ещё и возвращает недостающие файлы на место и никогда не заменяет существующие. См. [docs/restore.ru.md](docs/restore.ru.md) |
| `backupclaude doctor` | Найти проблему и подсказать решение |
| `backupclaude password` | Проверить наличие пароля, `--show` показывает его, чтобы записать на бумагу |
| `backupclaude notify` | Куда приходят сообщения о сбоях (`telegram`, `webhook`, `test`, `remove`) |
| `backupclaude schedule` | Задачи в Планировщике (`install`, `remove`, `status`) |
| `backupclaude update` | Найти более новый выпуск, сверить хэш, заменить программу. Настройки, расписание и копии не трогаются |
| `backupclaude uninstall` | Убрать задачи и программы. Копии и пароль остаются |
| `backupclaude install` | Скопировать программу в вашу папку и добавить в PATH (её запускает команда установки) |
| `backupclaude skill` | Поставить или убрать навык `/backup` для Claude Code |
| `backupclaude ui` | Открыть страницу в браузере: состояние с кнопкой **Сохранить сейчас**, снимки, восстановление, настройки. Завершается, когда вы закрываете вкладку. См. [docs/ui.ru.md](docs/ui.ru.md) |
| `backupclaude tray` | Показать значок состояния в области уведомлений (по умолчанию выключен; `--enable` запускает его при входе) |

Для скриптов добавьте к любой команде `--json`, язык выбирается через `--lang ru` или `--lang en`. Подробнее: [docs/install.ru.md](docs/install.ru.md).

## Что сохраняется

- **Профиль `claude`**, каждый час: вся папка `~/.claude` и файл `~/.claude.json`, а также данные приложения Claude, в обычной установке или из Microsoft Store. Токены входа (`.credentials.json`), кэши, логи и программы, которые ставятся заново, в снимок не идут. Полный список лежит в `manifests/`.
- **Профиль `projects`**, раз в сутки: папки, где работал Claude. Они находятся по транскриптам сессий и запоминаются после удаления старых сессий. К ним добавляются папки из `sources.extra` в настройках. Зависимости, виртуальные окружения и кэши не сохраняются, а внутри репозитория git не сохраняются ещё и папки сборки.

Домашняя папка и временные папки проектами не считаются. В `sources.exclude` полный путь исключает эту папку или файл, `*` в конце пути работает как маска, а просто имя исключает его на любой глубине. По умолчанию хранятся 48 почасовых, 30 суточных, 12 недельных и 24 месячных снимка (`retention.*`). Раз в неделю хранилище проверяется, а раз в четыре недели часть файлов восстанавливается и сверяется с оригиналами.

## Уведомления

О сбое плановой задачи вы узнаёте один раз, об успешных запусках сообщений нет. Так же приходит тревога, если число сессий Claude резко упало (больше чем на `notify.deletion_drop_percent` против прошлого запуска, по умолчанию 20), и если папка Claude была и пропала. Раз в неделю приходит сводка, даже когда всё хорошо. Каналы: Telegram (токен бота в системном хранилище ключей, id чата в `config.json`) и webhook (его адрес в хранилище ключей). Без канала программа работает и молчит, а `status` показывает те же факты.

## Страница в браузере

Если не хочется пользоваться командной строкой, выполните `backupclaude ui`: в браузере откроется небольшая страница и сразу покажет, в безопасности ли данные. С неё можно сохранить данные сейчас, посмотреть снимки, вернуть сессию или проект и изменить настройки. Она работает только с вашего компьютера, по разовой ссылке, никогда не показывает пароль и завершается, когда вы закрываете вкладку. Подробности и снимки экрана: [docs/ui.ru.md](docs/ui.ru.md).

## Восстановление

Без флагов в терминале `backupclaude restore` спрашивает, что вернуть, и показывает последние сессии. Пошаговые инструкции для пропавшей сессии, испорченного проекта и нового компьютера: [docs/restore.ru.md](docs/restore.ru.md). С навыком `/backup` можно и просто сказать Claude Code: «верни вчерашнюю сессию».

## Безопасность

- Данные шифруются на вашем компьютере до отправки. Хранилище видит только нечитаемые файлы.
- Пароль лежит в хранилище ключей системы: диспетчер учётных данных на Windows, связка ключей на macOS, Secret Service на Linux. Его не печатают, не пишут в журнал и не передают аргументом; restic получает его через `--password-command`. `password --show` работает только для человека в терминале. `password change` заменяет пароль во всех копиях (см. `docs/password.ru.md`).
- **Без пароля копии не открыть, и восстановить его никто не сможет.** Мастер показывает, как переписать его на бумагу.
- Восстановление никогда не заменяет существующий файл.
- Скачанные restic, rclone и обновления проверяются по SHA-256 до использования. restic и rclone закреплены в `tools.lock.json`.
- В транскриптах сессий могут быть токены и пароли, которые вы вводили за работой. Поэтому копии шифруются до выхода с компьютера, и поэтому общего пароля нет.
- `uninstall` не трогает ни копии, ни пароль в хранилище ключей.

## Ограничения

- **Автоматического копирования во внешнее хранилище пока нет.** `setup` принимает внешний адрес и хранит его в настройках, но эта версия туда не копирует, а `status` показывает внешнюю копию недоступной. Пока этот этап не сделан, при потере компьютера пропадёт и локальная копия. Держите локальную копию на другом физическом диске и не считайте её единственной защитой.
- Только Windows 10 и 11 (64-бит Intel/AMD). Части, зависящие от системы, в коде отделены, сборки для macOS и Linux в планах.
- Задачи идут в вашем сеансе Windows: когда компьютер выключен или в нём никто не вошёл, ничего не запускается, а пропущенный запуск стартует после входа. Файлы, которые держит открытыми работающая программа, пропускаются и сохраняются при следующем запуске.
- Для восстановления баз приложения Claude (Local Storage, IndexedDB) Claude должен быть закрыт; команда откажет и скажет об этом.
- Чаты claude.ai живут в облаке Anthropic и не сохраняются.
- `update` читает выпуски приватного репозитория только с токеном GitHub в `BACKUPCLAUDE_GITHUB_TOKEN`; без него команда так и говорит и завершается. `update --from-file` ставит файл, который вы скачали сами.
- Программа не подписана (см. [SmartScreen](#smartscreen)).
- Часовые снимки быстрые, но первый снимок проектов может занять полчаса и больше.

## Сборка

Нужен Go, версия указана в `go.mod`.

```
go build ./cmd/backupclaude
go test ./...
```

`scripts/e2e-windows.ps1` проходит всю цепочку на выдуманном профиле (установка, setup, backup, удаление файлов, restore, сверка хэшей, update, uninstall); CI запускает его на чистой Windows. На компьютере с настоящей установкой запускайте его с `-Sandbox имя`: папка задач, группа в хранилище ключей и ключ PATH получат это имя, а настоящие не будут затронуты.
