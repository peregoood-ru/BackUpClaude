# BackUpClaude

[English version](README.md)

> **Проект неофициальный.** Он не связан с Anthropic, компания его не поддерживает и не одобряла.

BackUpClaude бережёт ваши данные Claude и проекты: сессии, память и настройки Claude раз в час, папки проектов раз в сутки, в двух зашифрованных копиях: на локальном диске и во внешнем хранилище. Это один файл, ставить ничего больше не надо. Бэкап делают [restic](https://github.com/restic/restic) и [rclone](https://github.com/rclone/rclone): приложение устанавливает их само, закреплённых версий и со сверкой хэшей.

**Статус: ранняя разработка.** Снимки в локальный репозиторий идут по расписанию, `restore` возвращает сессию, проект или всё, а пробное восстановление раз в четыре недели проверяет копию. Внешняя копия и мастер настройки появятся на следующих этапах. Пока на него нельзя полагаться.

## Команды

| Команда | Что делает | Статус |
| --- | --- | --- |
| `backupclaude doctor` | Найти проблему и подсказать решение | работает |
| `backupclaude password` | Проверить наличие пароля, `--show` показывает его, чтобы записать на бумагу | работает |
| `backupclaude --version` | Версия приложения и закреплённых программ | работает |
| `backupclaude backup` | Снимок прямо сейчас, `--profile claude` или `projects` для одного из них, `--dry-run` ничего не сохраняет | работает |
| `backupclaude list` | Снимки, сессии и проекты | работает |
| `backupclaude status` | В безопасности ли данные, простыми словами: возраст последнего снимка в каждой копии, размер, свободное место, последняя проверка, сбои | работает |
| `backupclaude notify` | Настроить, куда приходят сообщения о сбоях (`telegram`, `webhook`, `test`, `remove`) | работает |
| `backupclaude setup` | Мастер настройки | в планах |
| `backupclaude restore` | Вернуть сессию (`--session`), проект (`--project`) или всё (`--all`) в новую папку; `--apply` ещё и возвращает недостающие файлы на место и никогда не заменяет существующие. См. [docs/restore.ru.md](docs/restore.ru.md) | работает |
| `backupclaude ui` | Открыть страницу в браузере | в планах |
| `backupclaude update` | Обновить приложение | в планах |
| `backupclaude uninstall` | Удалить приложение, копии остаются | в планах |

Для скриптов добавьте к любой команде `--json`, язык выбирается через `--lang ru` или `--lang en`.

## Восстановление

Без флагов в терминале `backupclaude restore` спрашивает, что вернуть, и показывает последние сессии. Пошаговые инструкции для пропавшей сессии, испорченного проекта и нового компьютера: [docs/restore.ru.md](docs/restore.ru.md).

## Уведомления

О сбое плановой задачи вы узнаёте один раз, об успешных запусках сообщений нет. Так же приходит тревога, если число сессий Claude резко упало (больше чем на `notify.deletion_drop_percent` против прошлого запуска, по умолчанию 20), и если папка Claude была и пропала: так выглядит переезд данных после обновления. Раз в неделю приходит сводка, даже когда всё хорошо. Каналы: Telegram (токен бота в системном хранилище ключей, id чата в `config.json`) и webhook (его адрес в хранилище ключей). Без канала программа работает и молчит, а `status` показывает те же факты.

## Что сохраняется

- **Профиль `claude`:** вся папка `~/.claude` и файл `~/.claude.json`, а также данные приложения Claude, в обычной установке или из Microsoft Store. Токены входа, кэши, логи и программы, которые ставятся заново, в снимок не идут. Полный список лежит в `manifests/`.
- **Профиль `projects`:** папки, где работал Claude. Они находятся по транскриптам сессий и запоминаются после удаления старых сессий. К ним добавляются папки из `sources.extra` в настройках. Зависимости, виртуальные окружения и кэши не сохраняются, а внутри репозитория git не сохраняются ещё и папки сборки.

Домашняя папка и временные папки проектами не считаются. В `sources.exclude` полный путь исключает эту папку или файл, `*` в конце пути работает как маска, а просто имя исключает его на любой глубине.

## Безопасность

- Данные шифруются на вашем компьютере до отправки. Хранилище видит только нечитаемые файлы.
- Пароль лежит в хранилище ключей системы: диспетчер учётных данных на Windows, связка ключей на macOS, Secret Service на Linux.
- **Без пароля копии не открыть, и восстановить его никто не сможет.** Запишите его на бумагу: `backupclaude password --show`.

## Сборка

```

go test ./...
```
